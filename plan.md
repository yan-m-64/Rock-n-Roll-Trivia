Rock-n-Roll-Trivia is a browser-based trivia game focused on rock and metal bands including Sum 41, Linkin Park, Breaking Benjamin, Escape the Fate, Falling in Reverse, Set It Off, Fall Out Boy, and Pierce the Veil. Players answer questions about band history, lyrics, and lore, earning a dancing skeleton animation on each correct answer.

Key UI components:
- Start screen with logo and "Start Game" button
- Question card showing question text and 4 multiple-choice answer buttons
- Score tracker and question counter (e.g. "Question 3 of 10")
- Correct/incorrect feedback overlay
- Dancing skeleton animation (CSS or Lottie/GIF) triggered on correct answers
- End screen showing final score and "Play Again" button

JavaScript functionality:
- Question bank array with band, question, answer choices, and correct answer fields
- Shuffle/randomize question order each game
- Answer selection logic with immediate right/wrong feedback
- Score increment on correct answer + trigger skeleton dance animation
- Progress through question set, then display results screen
- Timer per question (optional stretch goal)

Color scheme and visual style:
- Dark background (#0d0d0d or deep charcoal)
- Electric red and bone-white accents
- Distressed or grunge-style typography (Google Font: Metal Mania or Permanent Marker)
- Subtle skull/rock motif border elements
- High contrast, bold button styles
